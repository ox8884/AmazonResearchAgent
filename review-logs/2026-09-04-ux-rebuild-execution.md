## 현재 발견

- 현재 활성 소스는 프로젝트 루트(main), Cloudflare 배포 구조가 존재한다. 역사적인 별도 worktree를 수정하지 않는다.
- `dashboard-data.ts`의 후보 요약은 candidate_evidence를 조회하지 않는다.
- `decision-call.tsx`는 rule reason 존재 여부를 hasEvidence로 사용하여 reason이 있으면 근거가 충분하다고 표시한다. 실제 수집 자료와 무관하다.
- 후보 목록도 rule reason 부재를 자료 부재 문구로 표시한다.
- 상세는 모든 근거를 부족한 근거 아래에 배치하고, 배열/객체를 items/structured data로 축약한다.
